# .sdkwork Workspace

Source-controlled workspace metadata for SDKWork Doctor. Runtime state is never stored here.

- `skills/`: repository-local agent skills.
- `plugins/`: repository-local agent plugins.
- `local/`, `tmp/`, `cache/`, `secrets/`, `manual-backups/`: ignored local-only state.

Authority: `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`.
